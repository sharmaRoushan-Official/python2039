Q2.  Find the factorial of a given number using a loop.
>>>
   n = int(input("Enter a number: "))
   fact = 1

   for i in range(1, n + 1):
       fact *= i
   print("Factorial =", fact)

Q2.  Write a function to check whether a number is prime.
>>>
   def prime(n):
       if n <= 1:
           return False
       for i in range(2, n):
           if n % i == 0:
               return False
       return True
   
   n = int(input())

   if prime(n):
       print("Prime")
   else:
       print("Not Prime")
